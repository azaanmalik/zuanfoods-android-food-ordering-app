# Security and privacy

ZuanFoods is an offline/static UI demonstration, not a production food-ordering service. No real payments, customer accounts or backend orders are implemented.

- Never commit credentials, signing keys, customer details or private order data.
- The email-order intent requires an email client and a recipient configured by the person running the app; it is not a secure order-processing system.
- Review the provenance and licensing of sample food images before commercial reuse.
- Validate and secure any future server-side ordering, authentication and payment functionality independently.
- Report security concerns privately to the repository maintainer through their GitHub profile contact information.
